## In one paragraph

The authors build JAZ, an agent framework around one primitive, `invoke`: a function whose body a model writes, as Python code, each time it is called. The model works in a running Python session, a **REPL**, and its code can call `invoke` again, so subagents are the default. Everything the model sees, including its own history, is a variable its code can use. With only prompting, they report that this loop beats specialized harnesses for long-term memory and for self-improvement, at similar or lower cost.

## How to read it for this course

About 25 minutes.

- **Read closely:** the [abstract](https://arxiv.org/html/2609.26891) and [1 Introduction](https://arxiv.org/html/2609.26891#S1).
- **If you have time:** [2.2](https://arxiv.org/html/2609.26891#S2.SS2) for the two defining properties, and the rules for the "prompt-only" setup in [C.1](https://arxiv.org/html/2609.26891#A3.SS1) before you trust the numbers.
- **Skip:** the formal semantics in [2.3](https://arxiv.org/html/2609.26891#S2.SS3) and [Appendix A](https://arxiv.org/html/2609.26891#A1).
- **S09, Checkpoint: the minimalist's challenge.** Optional. Read it as the minimalist's strongest case, then list what its "minimal" loop still contains.

## What it shows

Both results are measurements by the framework's authors.

- **Long recall without a memory system.** On the recall-heavy part of StuLife, with GPT-5.4 nano, JAZ scores 70%, against 32% for CodeAct with subagents and 62% for Letta (MemGPT), a specialized long-horizon harness ([1](https://arxiv.org/html/2609.26891#S1)). When its context fills, the agent hands the rest of the task to a subagent, passing its full history by reference. Each method ran three times ([4.1](https://arxiv.org/html/2609.26891#S4.SS1)).
- **Self-improvement without a dedicated loop.** On AppWorld, with GPT-5.4 at the top and GPT-5.4 nano below, JAZ scores 74%, against 68% for CodeAct, 71% for CodeAct with subagents and 70% for ACE, a specialized self-improvement harness ([1](https://arxiv.org/html/2609.26891#S1)).

## Where it is weak

- No coding tasks. StuLife simulates a college semester, and AppWorld simulates the APIs of 9 apps ([4.1](https://arxiv.org/html/2609.26891#S4.SS1), [4.2](https://arxiv.org/html/2609.26891#S4.SS2)). Every run uses GPT-5.4 or GPT-5.4 nano.
- The minimal loop still has a harness. JAZ truncates long REPL output by default ([Configuration system](https://arxiv.org/html/2609.26891#S3.SS0.SSS0.Px3)), and "prompt-only" allows budget control, step limits, a completion guard and context-window warnings ([C.1](https://arxiv.org/html/2609.26891#A3.SS1.SSS0.Px5)). The long-horizon result relies on a hook that injects a message when the context window is 70% full ([C.2.2](https://arxiv.org/html/2609.26891#A3.SS2.SSS2)). And the StuLife tools were rewritten to take structured inputs, validate them, and carry code examples in their docstrings ([C.2.1](https://arxiv.org/html/2609.26891#A3.SS2.SSS1)): tool design, the subject of A2.
- The authors reran both CodeAct baselines inside JAZ because, they report, the established versions did worse through defects in prompting and REPL implementation ([4](https://arxiv.org/html/2609.26891#S4)). For Letta they kept the one prompt that did not loop forever ([C.2.2](https://arxiv.org/html/2609.26891#A3.SS2.SSS2)).
- The AppWorld margin is small. One of the six JAZ runs scored below the CodeAct baseline ([Appendix D](https://arxiv.org/html/2609.26891#A4)).

## What it means for your harness

S09 calls this the strongest case that the loop alone is enough. The paper's claim is narrower: a code-writing loop with subagents and its history as data can replace memory and self-improvement add-ons. It still truncates output and keeps budgets, so the fair minimal arm in your ablation is bash plus truncation, not bare bash.

Two differences matter. Your model calls tools through `tool_use` blocks, while JAZ's model replies with nothing but code. And your `messages` list is not data the model can search. Both return in M3, where your history grows until the API refuses it, and in S24, where you add a subagent.

C.1 also models good measurement: prompts byte-identical except where a difference is necessary. Keep your two S09 arms identical apart from the tools.

## In their words

> "Together, these results show that prompting a minimal agent loop is sufficient to elicit long-horizon and self-improvement capabilities, rather than requiring specialized external harness components."
>
> Source: [1 Introduction](https://arxiv.org/html/2609.26891#S1). Li et al. 2026, CC BY 4.0.

> "There is no loop-external logic that modifies the loop itself (e.g., truncating the conversation history, injecting variables in the REPL). However, monitoring is allowed: budget control, step limits, recursion limit, completion guard, and context-window limit warnings."
>
> Source: [C.1 Evaluation Protocol](https://arxiv.org/html/2609.26891#A3.SS1.SSS0.Px5). Li et al. 2026, CC BY 4.0.
